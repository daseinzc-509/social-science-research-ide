# AGENTS.md — SRA 桌面端交互架构与 UX 规范

本规则适用于 `desktop/SRA.Desktop/` 下的全部界面、布局、菜单与交互开发。遵循经典桌面文献工作台（如 NoteExpress）的“直给、联动、就地操作”心智与 Material Design 3 视觉体系，严禁引入“Web 化杂物抽屉”反模式。

## 1. 反“杂物抽屉”与操作归位红线

1. **禁止使用大杂烩 `•••` 溢出菜单**：
   - 文档页主操作栏只放高频、意图明确的直给按钮（如 `开始分析`、`打开 PDF`、`局部复核`、`导出 ▾`、`专注阅读`）。
   - 禁止把归类/加入专题、元数据编辑、多种导出格式、维护/删除操作混装进通用 `•••` 菜单。
2. **就地操作原则（In-Place Actions）**：
   - 题录/元数据编辑放在「概览 → 书目信息」卡片旁；所属研究专题直接以芯片形式展现在右侧「研究画像」中并提供 `＋ 归入专题`；参考文献操作留在「参考文献」Tab 顶部。
3. **原生桌面右键菜单（ContextMenu）必填**：
   - 论文列表项与研究专题文件夹节点必须提供贴合对象上下文的右键菜单，让鼠标用户无需先选中再长途寻找顶部按钮。
4. **低频与危险操作物理隔离**：
   - 「重建 PDF 解析」「删除论文」等低频维护/不可逆操作置于对象右键菜单分隔线下方，并在「概览」底部提供清晰的维护卡片（兼顾触控板用户），所有不可逆删除必须经 `ConfirmWindow` 明确告知后果。

## 2. 目录树联动与导航架构

1. **专题文件夹与文献库统一联动**：
   - 文献视图（全部论文 / 已分析 / 待分析）与**研究专题（项目）**统一以左侧目录树组织，点击专题节点即刻筛选文献列表，并在主区顶部提供 `单篇精读 | 专题证据矩阵` 轻量切换，绝不将「专题/项目」做成与文献库割裂的平行顶栏页面。
2. **顶栏克制与系统工具分级**：
   - 顶栏与导航保持层次分明，不被不断累加的平级按钮撑爆；优先维护高频快捷键（`Ctrl+F` 搜索、`Ctrl+/` 专注阅读、`Ctrl+O` 导入、`Esc` 清空）。

## 3. 视觉与契约底线

- 全部新增控件、右键菜单、专题芯片与弹窗 100% 复用 `App.axaml` 的 MD3 动态资源令牌（Light / Dark 实时自适应），禁止硬编码色值。
- 修改前核对根目录 `AGENTS.md` 中的全部 XAML 静态回归契约；完成后 `dotnet build -c Release` 必须保持 0 警告 0 错误。
